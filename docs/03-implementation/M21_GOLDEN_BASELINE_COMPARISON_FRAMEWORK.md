# M21 — Golden Baseline Comparison Framework

## Purpose

M21 establishes the evidence model for comparing Native V2 rendered templates against the V1 Golden Baseline.

The comparison is explicitly evidence-driven. It does not infer visual equivalence from source similarity.

## Dimensions

Each template may be compared across:
- typography;
- color;
- spacing;
- hierarchy;
- columns;
- photo treatment;
- icons;
- backgrounds;
- page structure;
- content visibility;
- pagination.

## Result classification

Every dimension must be classified as one of:
- identical/within tolerance;
- intentional difference;
- compatibility adaptation;
- regression;
- insufficient evidence.

A regression is blocking. Insufficient evidence prevents compatibility certification but is not itself a regression.

## Baseline identity

Every comparison fixture identifies:
- V1 baseline ID;
- template ID;
- controlled viewport;
- A4 page model;
- representative fixture data ID;
- expected/evidence records.

## Important rule

The framework does not manufacture screenshot or geometry evidence. Real browser evidence must be attached to the fixture before a dimension can be certified.
