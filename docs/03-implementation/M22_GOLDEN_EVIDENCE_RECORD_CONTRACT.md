# M22 Evidence Record Contract

Each comparison observation is stored as an evidence record.

A certified result must identify a reference artifact. This prevents a visual or geometry claim from becoming a status merely because a test author asserted it.

Evidence may later point to:
- V1 screenshot;
- V2 screenshot;
- geometry measurement artifact;
- rendered PDF;
- pagination report;
- documented intentional-change record.

The framework intentionally does not prescribe a particular storage provider.
