# M2088–M2167 — CV ATS Analysis Contract

## Purpose
Establish a deterministic ATS-readiness analysis boundary over the document snapshot.

## Contract
- Analyze source structure and optional job keywords.
- Report checks, keyword matches/missing keywords, counts, and a bounded 0–100 diagnostic score.
- Keep the analysis explainable through individual checks.
- Do not claim that a score represents any specific external ATS vendor's proprietary algorithm.
- Keep AI/provider selection outside this boundary.

## Validation
The milestone suite covers keyword matching, source counts, bounded scoring, and invalid-result handling.
